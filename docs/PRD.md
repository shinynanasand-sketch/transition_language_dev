# PRD — 일상 속 한국어를 조금씩 일본어로

## 제품 한 줄

내 일상 속 한국어를 매일 조금씩 일본어로 바꿔 가는 학습 서비스입니다. 일기를 통째로 번역하지 않고, 문장 안에 외국어를 침투시킵니다.

## 타겟 유저

- 한국어가 모어인 학습자. 처음부터 완전한 일본어 작문은 부담인 사람
- 카카오톡으로 오늘 일과를 보내고, 빈칸만 채우고 싶은 사람
- 웹훅 JSON과 UX를 목업으로 검증하려는 개발·기획자

## 핵심 시나리오

사용자가 보낸다.

```
오늘 회사에서 일이 별로 없었다.
점심으로 돈까스를 먹었다.
집에 와서 게임을 했다.
```

Lv.1(명사)에서는 한국어를 유지한 채 핵심만 빈칸이다.

```
오늘 [　　]에서 일이 별로 없었다.
점심으로 [　　]를 먹었다.
집에 와서 [　　]을 했다.
```

선택지 또는 직접 입력으로 `会社` / `とんかつ` / `ゲーム`를 채운다. 맞히면 한국어 문장 속에 일본어가 섞인다.

```
오늘 会社(かいしゃ)에서 일이 별로 없었다.
점심으로 とんかつ를 먹었다.
집에 와서 ゲーム을 했다.
```

## 레벨 (서비스 발전 구조)

| 레벨 | 빈칸 범위 | 한:일 감각 |
| --- | --- | --- |
| Lv.1 명사 | 오늘 [会社]에서 일이 별로 없었다. | 한국어 90% + 일본어 10% |
| Lv.2 동사/형용사 | 오늘 회사에서 일이 별로 [なかった]. | ~70:30 |
| Lv.3 짧은 표현 | 오늘 회사에서 [あまり仕事がなかった]. | ~50:50 |
| Lv.4 문장 일부 | [今日は会社で] 일이 별로 없었다. | 일본어 80% |
| Lv.5 전체 문장 | 원문을 일본어로 직접 작성 | 일본어 100% |

MVP 기본은 **Lv.1**. 칩으로 레벨만 바꿀 수 있고, 계정·진도 DB는 없다.

## 검증 전략: 웹 목업 UI

카카오 오픈빌더 연동 전에 FastAPI `GET /` 목업이 Skill JSON으로 `POST /api/chat`을 호출한다.

## 성공 기준 (MVP)

- 일기 전송 → 빈칸 한국어 + 일본어 선택지
- 정답 입력 → 읽기(ふりがな)가 붙은 한·일 혼합 문장
- Skill 응답 2.0 유지, LLM 실패 시에도 같은 JSON

## 비범위

- 오픈빌더 실제 연동, 계정/DB, TTS, 이미지 카드
- 통번역·문법 강의형 전체 일본어 해설
